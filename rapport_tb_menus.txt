# ANALYSE DE LA TABLE TB_MENUS

## FICHIERS UTILISANT TB_MENUS

1. **application/models/Archive_model.php**
   - Méthode `get_menus_by_role($role)` (ligne 26-32)
   - Exécute la requête: `SELECT * FROM tb_menus WHERE min_role >= $role ORDER BY id_menu ASC`

2. **application/controllers/Archive.php**
   - Dans le constructeur (ligne 12-16)
   - Initialise `$this->data['menus']` avec les résultats de `get_menus_by_role()`

3. **application/views/header.php**
   - Affiche les menus dans la navbar (ligne 33-44)
   - Utilise la variable `$menus` passée depuis le contrôleur

## RÔLE DE LA TABLE

La table `tb_menus` est utilisée pour gérer la navigation dynamique de l'application en fonction des rôles des utilisateurs. Elle permet de:

1. **Contrôle d'accès basé sur les rôles** :
   - Chaque menu a un `min_role` qui détermine le niveau minimum requis pour voir ce menu
   - Les utilisateurs avec un rôle inférieur ne voient pas ces menus

2. **Génération dynamique de la navbar** :
   - La navbar est générée automatiquement en fonction des menus disponibles pour l'utilisateur
   - Les menus sont affichés dans l'ordre défini par le champ `ordre`

3. **Centralisation de la gestion des menus** :
   - Permet de modifier les menus sans toucher au code
   - Facilite l'ajout/suppression de menus

## STRUCTURE ATTENDUE DE LA TABLE

D'après l'analyse du code, la table `tb_menus` devrait avoir la structure suivante:

| Champ       | Type         | Description                                                                 |
|-------------|--------------|-----------------------------------------------------------------------------|
| id_menu     | int(11)      | Clé primaire, auto-incrément                                               |
| menu        | varchar(100) | Nom du menu (ex: "Accueil", "Pré-archives")                                 |
| lien        | varchar(255) | URL du menu (ex: "archive", "prearchive")                                   |
| icone       | varchar(50)  | Classe de l'icône (ex: "fas fa-home")                                      |
| min_role    | int(11)      | Rôle minimum requis pour voir ce menu (1=admin, 2=gestionnaire, etc.)      |
| ordre       | int(11)      | Ordre d'affichage dans la navbar                                           |
